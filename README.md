# CountryPeek

A React app to search and explore countries using RestCountries API.

## 🔗 Live Demo
https://your-live-url-here

## Features
- Search countries
- Filter by region
- Sort by name & population
- Country detail page
- Dark/light theme
- Favourites with persistence

## Tech Stack
React, Vite, React Router, Context API, useReducer, CSS

## Run Locally
```bash
npm install
npm run dev
```
